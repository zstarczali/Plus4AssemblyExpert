# Color Codes

- Source: https://plus4world.powweb.com/plus4encyclopedia/500025
- Category: Programming/Assembly

The Plus/4 can display 121 colors by default. We have 16 colors * 8 luminance values = 128, but all 8 blacks are the same. So the total number of colors is 15 * 8 + 1 = 121.

Color codes for $FF15, $FF16, etc:
00 : Black
01 : White
02 : Red
03 : Cyan
04 : Purple
05 : Green
06 : Blue
07 : Yellow
08 : Orange
09 : Brown
0A : Yellow-Green
0B : Pink
0C : Blue-Green
0D : Light Blue
0E : Dark Blue
0F : Light Green
