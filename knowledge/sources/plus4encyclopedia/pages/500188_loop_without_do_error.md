# ?LOOP WITHOUT DO ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500188
- Category: Reference/BASIC Error Messages

This occurs if a LOOP or EXIT statement is encountered outside of a DO loop.

Also see the [DO/LOOP/WHILE/UNTIL/EXIT statement](500072_do_loop_while_until_exit_statement.md).
