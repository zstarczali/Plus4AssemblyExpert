# STOP Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500109
- Category: Reference/Commodore BASIC V3.5

STOP

When the STOP statement is executed, program execution is stopped, and a BREAK IN LINE # message appears showing the line number where the STOP statement was encountered (unless used in direct mode, where only BREAK is displayed). Program execution may be continued with the [CONT command](500041_cont_command.md).

This is similar to the [END statement](500074_end_statement.md), but the END statement only displays a READY prompt when executed.

Abbreviation
S SHIFT+T
