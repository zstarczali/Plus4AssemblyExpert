# ?CAN'T CONTINUE ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500181
- Category: Reference/BASIC Error Messages

An attempt was made to continue program execution with the [CONT command](500041_cont_command.md) either before the program was run; after reentering a BASIC line; after the program stopped due to an error; or causing an error in direct mode before restarting.
