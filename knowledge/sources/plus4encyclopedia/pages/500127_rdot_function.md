# RDOT Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500127
- Category: Reference/Commodore BASIC V3.5

RDOT(X)

This function returns a numeric value.

This function returns information about the [pixel cursor](500204_pixel_cursor.md).

X is a value from 0-2. RDOT(0) gives the x-position of the pixel cursor, RDOT(1) gives the y-position of the pixel cursor, and RDOT(2) indicates which of the [color sources](500063_color_sources.md) the pixel cursor is using.

Abbreviation
R SHIFT+D
