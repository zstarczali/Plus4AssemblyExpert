# ?BREAK ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500185
- Category: Reference/BASIC Error Messages

This error message does not usually appear as ?BREAK ERROR, but only as BREAK. It appears whenever a program is stopped with the RUN/STOP key, or if the program encounters a [STOP statement](500109_stop_statement.md). It only appears as ?BREAK ERROR if RUN/STOP is pressed during tape or disk operations.
