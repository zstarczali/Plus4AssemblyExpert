# How Do I Disable LIST Function?

- Source: https://plus4world.powweb.com/plus4encyclopedia/500208
- Category: Programming/BASIC

Use POKE 775,128 in your BASIC program. It's full.
Use POKE 774,178 in your BASIC program. Only stopped with Run/Stop + Reset.
Use POKE 774,187 in your BASIC program. If use the LIST then you see only numbers.

and Enable it back with POKE 774,0.
