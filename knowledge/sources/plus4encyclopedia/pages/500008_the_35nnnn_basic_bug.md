# The "35nnnn" BASIC Bug

- Source: https://plus4world.powweb.com/plus4encyclopedia/500008
- Category: Programming/General
- Keywords: Bug

Typing any number between (and including) 350720 and 353279 and pressing return will 'crash' your Commodore's BASIC. Only the first six numbers matter, additional numbers or even letters can be added, but they are ignored. (Sometimes this bug is reported as 35072121, which of course also causes this problem.)
