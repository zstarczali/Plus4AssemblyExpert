# FRE Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500145
- Category: Reference/Commodore BASIC V3.5

FRE(X)

This function returns a numeric value.

This function returns the number of bytes available to BASIC. X is a dummy argument.

It also triggers a garbage collection which frees up memory that was previously allocated to variables but is no longer in use.

Abbreviation
F SHIFT+R
