# CLR Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500066
- Category: Reference/Commodore BASIC V3.5

CLR

This statement erases all variables, arrays and functions in memory, but leaves the program intact.

It will also reset the DATA pointer, disable any active GOSUBs, disable any active FOR or DO loops, disable TRAP, clear the contents of HELP, and deactivate any open files and any associated CMD redirects.

CLR is automatically performed when the [RUN command](500057_run_command.md) or [NEW command](500052_new_command.md) is given, or if any program editing is performed.

Abbreviation
C SHIFT+L
