# END Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500074
- Category: Reference/Commodore BASIC V3.5

END

When the END statement is executed, program execution is stopped. Program execution may be continued with the [CONT command](500041_cont_command.md).

This is similar to the [STOP statement](500109_stop_statement.md), but does not display a BREAK message with the line number where END was encountered.

Abbreviation
E SHIFT+N
