# Color Codes

- Source: https://plus4world.powweb.com/plus4encyclopedia/500107
- Category: Programming/BASIC
- Keywords: Color codes

These are the default color codes. They are taken from memory location $0113 (275).

| Keyboard shortcut | Color name | Color code | BASIC Equivalent |
|---|---|---|---|
| CTRL+1 | Black | $00 | COLOR 1, 1, 0 |
| CTRL+2 | White | $71 | COLOR 1, 2, 7 |
| CTRL+3 | Red | $32 | COLOR 1, 3, 3 |
| CTRL+4 | Cyan | $63 | COLOR 1, 4, 6 |
| CTRL+5 | Purple | $44 | COLOR 1, 5, 4 |
| CTRL+6 | Green | $35 | COLOR 1, 6, 3 |
| CTRL+7 | Blue | $46 | COLOR 1, 7, 4 |
| CTRL+8 | Yellow | $77 | COLOR 1, 8, 7 |
| C=+1 | Orange | $48 | COLOR 1, 9, 4 |
| C=+2 | Brown | $29 | COLOR 1, 10, 2 |
| C=+3 | Yellow-green | $5A | COLOR 1, 11, 5 |
| C=+4 | Light Red | $6B | COLOR 1, 12, 6 |
| C=+5 | Blue-Green | $5C | COLOR 1, 13, 5 |
| C=+6 | Light Blue | $6D | COLOR 1, 14, 6 |
| C=+7 | Dark Blue | $2E | COLOR 1, 15, 2 |
| C=+8 | Light Green | $5F | COLOR 1, 16, 5 |
