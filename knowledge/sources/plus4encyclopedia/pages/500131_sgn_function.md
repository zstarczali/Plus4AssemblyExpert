# SGN Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500131
- Category: Reference/Commodore BASIC V3.5

SGN(X)

This function returns a numeric value.

This function returns the SiGN (positive, negative, zero) of the value in X.

The results are
1: Positive
0: Zero
-1: Negative

Abbreviation
S SHIFT+G
