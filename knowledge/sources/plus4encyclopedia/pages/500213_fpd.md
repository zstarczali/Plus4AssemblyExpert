# FPD

- Source: https://plus4world.powweb.com/plus4encyclopedia/500213
- Category: Glossary/Demos
- Keywords: fpd,flexible pixel distance See Also [FPS](https://plus4world.powweb.com/kb.php?id=500227)

FPD stand for Flexible Pixel Distance.
It may look like [FLD](https://plus4world.powweb.com/kb.php?id=500028), but now you can have have variable distance between each pixel lines. From top to down: 1 line of gfx, some empty space, another line of gfx, empty space, and so on.
