# SCRATCH Command

- Source: https://plus4world.powweb.com/plus4encyclopedia/500059
- Category: Reference/Commodore BASIC V3.5

SCRATCH "*filename*" [,D*drive#*] [,U*unit#*]

Deletes a file from the disk directory. WARNING: Be sure you want to delete the file. As a precaution, an ARE YOU SURE? message appears when executing this command. Enter Y to proceed, any other key to quit.

Example
`SCRATCH "MY BACK"`  Deletes the file "MY BACK"
`SCRATCH "MY BACK",U9`  Deletes the file "MY BACK" on device 9

Abbreviation
SC SHIFT+R
