# ?DEVICE NOT PRESENT ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500056
- Category: Reference/BASIC Error Messages

This error occurs if you try to access a peripheral that is not available. For example: issuing a [DIRECTORY command](500044_directory_command.md) with no disk drive connected, or the disk drive turned off. It will also occur if an END-OF-TAPE marker is found while loading from tape.

ERR$ error number
5
