# ABS Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500115
- Category: Reference/Commodore BASIC V3.5

ABS(X)

This function returns a numeric value.

The ABSolute function returns the positive value of the argument X.

Example:

```
?ABS(-2)  Prints 2
```

Abbreviation
A SHIFT+B

BASIC Token
$B6
