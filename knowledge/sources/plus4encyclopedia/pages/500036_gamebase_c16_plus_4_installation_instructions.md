# Gamebase C16/Plus 4 Installation Instructions

- Source: https://plus4world.powweb.com/plus4encyclopedia/500036
- Category: History
- Keywords: Gamebase

Hope these help:

Firstly download and install the Gamebase front end from www.bu22.com

Install the Gamebase installation file onto your computer

Go into the folder where Gamebase has been installed.

Run the program GBToolbox, click on file, then New Gamebase

Enter the name C264 and press enter

Download the Commodore 16/Plus 4 Gamebase (from www.commodore16.com) and unzip the folder and copy it over into the main Gamebase folder. Over writing any existing files.

Run Gamebase

Click on the GEMUS icon, and then 1.Winvice. Click browse, go into the Winvice folder in the C264 folder. Highlight xplus4 and click ok. (Yape will replace Winvice as soon as its fully compatable)

Click on the Tools menu icon, click on paths, change the Games and Pictures paths to corrispond to their location within the C264 folder on your hardrive.

Your done and ready to use the Gamebase
