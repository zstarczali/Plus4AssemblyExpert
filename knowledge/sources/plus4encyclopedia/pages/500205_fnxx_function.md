# FNxx Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500205
- Category: Reference/Commodore BASIC V3.5

FNxx(X)

This function returns a numeric value.

This returns the value generated by the user-defined function xx. For more information, see the [DEF FN statement](500070_def_fn_statement.md).

Abbreviation
None
