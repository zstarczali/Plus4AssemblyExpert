# International Standards

- Source: https://plus4world.powweb.com/plus4encyclopedia/500226
- Category: FAQ, History, Programming/General
- Keywords: standards,international,game,games,crack,hack,postfix

After an initial time of confusion and misunderstandings, several C64 cracking/hacking groups taking part of "Danish Gold Copy Party" in 1987 signed and released the text demo [New International Standards](http://noname.c64.org/csdb/release/?id=10236), in order to freeze and spread the general recognizable standards to be used as postfixes in the filenames of cracked games. [This](https://plus4world.powweb.com/images/misc/1987_int_release_standards.jpg) is the original piece of sheet where they first listed'em.
Compared to the early international standards'rules, nowaday some more postfixes have been added in order to cover all the possible cases. The "SID" is specifically dedicated to the Plus/4 scene.
Both '+' and '&' are also used in their significance of 'and'. Being '+' also for trainers, a trainerless release could use '&' instead.
The [release standards for cracks in CSDb](http://csdb.dk/forums/?roomid=8&topicid=58095), reported in the homonymous forum, represents a very elucidative text about how a 'crack' can be defined and treated in general.

| **+(number)** | (number) trainers |
|---|---|
| **+** | normal unlimited lives trainer; obsolete |
| **++** | from leveltrainer to long trainer menu, any '+' counts for unique trainers (e.g., infinite lives player 1 and player 2 count like one); obsolete |
| **+M** | originally "megatrainer", that is ingame modifications (new features, additional keys for more trainers which can be changed while game is playing...) |
| **100%** | bugfix of a previous crack |
| **101%/102%** | improved/bugfixed game with new and/or better features |
| **C** | game's own cheat mode, both reported or activated |
| **-** | preview or unfinished |
| **Pic** | with picture, the old **!** is also used; obsolete, **G** is preferred |
| **G** | debated: additional graphics, or more than one key initiating in-game trainer |
| **D** | with documents, the old **#** ("with instructions") is also used as filetag on disk only |
| **%** | with intro, used as filetag on disk only |
| **&** | with music, used as filetag on disk only; obsolete, nowadays few cracker groups prefer to use it in spite of **+** when no trainer is involved |
| **F** | also FX and FIX, NTSC<->PAL fix followed by [pal/ntsc] or [ntsc/pal] at the end, original format first |
| **H** | highscores-saver installed |
| **J** | joystick control added (if not present in original) |
| **P** | with password file or listed |
| **E** | debated: editor included, but also meaning english translation |
| **T** | translated, language also used (**E** english, **G** german, **I** italian...) |
| **S** | solution |
| **W** | walkthrough |
| **SID** | SIDcard version |
