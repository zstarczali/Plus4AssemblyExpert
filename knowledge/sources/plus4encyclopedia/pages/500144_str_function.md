# STR$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500144
- Category: Reference/Commodore BASIC V3.5

STR$(X)

This function returns string data.

This function converts a numeric value into a string. It is the opposite of the [VAL function](500136_val_function.md).

Examples
`STR$(123.456)`  Returns the string "123.456"
`STR$(3E-03)`  Returns the string "3E-03"

Abbreviation
ST SHIFT+R
