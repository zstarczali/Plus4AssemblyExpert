# SVS-OS Audio Commands

- Source: https://plus4world.powweb.com/plus4encyclopedia/500206
- Category: Programming/Audio, Programming/BASIC
- Keywords: music, sound, play Credits [S\_/S](https://plus4world.powweb.com/members/SVS) See Also [SVS-OS](https://plus4world.powweb.com/software/SVS-OS) 3.2

[SVS-OS](https://plus4world.powweb.com/software/SVS-OS) has an alternative to the BASIC VOL/SOUND commands, that allows an easier way to write/hear music in a BASIC-like syntax. Only one command (called PLAY) and you are enabled to listen to a string of music with notes, pauses, voices, volumes, etc.

Examples:
PLAY,"DO SOL /4 DO# >2"
PLAY,A$  (where A$ is a standard BASIC string variable)

Enjoy!
