# SQR Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500133
- Category: Reference/Commodore BASIC V3.5

SQR(X)

This function returns a numeric value.

This function returns the SQuare Root of X, where X is a positive number or 0. If X is negative, an [?ILLEGAL QUANTITY ERROR](500171_illegal_quantity_error.md) occurs.

Abbreviation
S SHIFT+Q
