# MONITOR Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500087
- Category: Reference/Commodore BASIC V3.5

MONITOR

This statement takes the computer out of BASIC mode and activates [TEDMON](500086_tedmon.md), the built-in machine language monitor. When in the monitor, entering X returns to BASIC mode.

Abbreviation
M SHIFT+O
