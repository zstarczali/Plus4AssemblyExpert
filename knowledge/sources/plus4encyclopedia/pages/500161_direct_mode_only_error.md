# ?DIRECT MODE ONLY ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500161
- Category: Reference/BASIC Error Messages

Some commands can only be used in direct mode. Using them in program mode will cause this error.

Example
`0 AUTO
RUN`  running this short program will cause this error.

ERR$ error number
34

See Also
?ILLEGAL DIRECT ERROR
