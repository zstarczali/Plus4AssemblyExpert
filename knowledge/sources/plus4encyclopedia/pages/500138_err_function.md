# ERR$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500138
- Category: Reference/Commodore BASIC V3.5

ERR$(X)

This function returns string data.

This function returns the error message associated with the error message number specified in X (1-36).

This function is often used in conjunction with the [TRAP statement](500111_trap_statement.md).

Examples
`ERR$(14)`  Returns the string ILLEGAL QUANTITY, which has the error code 14

Abbreviation
E SHIFT+R
