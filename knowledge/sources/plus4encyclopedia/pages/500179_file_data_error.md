# ?FILE DATA ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500179
- Category: Reference/BASIC Error Messages

This occurs when a program attempts to read numeric data from an open file, but receives string data instead.

In the first version of BASIC for the Commodore PET, this error was known as ?BAD DATA ERROR, which was incorrectly shown in the instruction manuals for the VIC-20 and C64.

24
