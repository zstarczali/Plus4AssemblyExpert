# ?SYNTAX ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500168
- Category: Reference/BASIC Error Messages

This error occurs when BASIC is unable to interpret a command or statement. This usually occurs when there is a missing quotation mark, missing or extra brackets in an expression, or misspelling a BASIC keyword. It can also occur if either the [SPC function](500147_spc_function.md) or [TAB function](500148_tab_function.md) is used as part of a variable expression.

Examples
`PRIMT"TEST"`  Causes the error, as PRINT is misspelled
`PRINT A+(B-(C)`  Causes the error, as there is a missing bracket

ERR$ error number
11
