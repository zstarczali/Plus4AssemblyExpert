# CLOSE Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500065
- Category: Reference/Commodore BASIC V3.5

CLOSE *file#*

This statement completes and closes any files used by the [OPEN statement](500089_open_statement.md). The number following CLOSE is the file number to be closed. Closing a file which was not open does not cause an error.

Examples
`CLOSE 2`  Logical file 2 is closed

Abbreviation
CL SHIFT+O
