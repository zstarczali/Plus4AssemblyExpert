# CHR$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500137
- Category: Reference/Commodore BASIC V3.5

CHR$(X)

This function returns string data.

This function returns a string character with the CHR$ code specified in X (0-255). (If X is negative or greater than 255, [?ILLEGAL QUANTITY ERROR](500171_illegal_quantity_error.md) occurs.) It is the opposite of the [ASC function](500116_asc_function.md).

Abbreviation
C SHIFT+H
