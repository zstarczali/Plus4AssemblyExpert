# SPC Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500147
- Category: Reference/Commodore BASIC V3.5

SPC(X)

This function is used by the [PRINT statement](500094_print_statement.md) to skip over X spaces from the last printed item. X can have a value from 0-255.

This is similar to the [TAB function](500148_tab_function.md), but counts spaces from the end of the last printed item.

The SPC function cannot be used as part of a variable expression. Otherwise a [?SYNTAX ERROR](500168_syntax_error.md) will occur.

Abbreviation
S SHIFT+P
