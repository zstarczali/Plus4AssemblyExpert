# RCLR Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500126
- Category: Reference/Commodore BASIC V3.5

RCLR(X)

This function returns a numeric value.

This function returns the number of the color assigned to one of the [color sources](500063_color_sources.md) specified in X (0-4).

To find the color luminance, use the [RLUM function](500129_rlum_function.md).

Abbreviation
R SHIFT+C
