# LDY

- Source: https://plus4world.powweb.com/plus4encyclopedia/500157
- Category: Reference/6502, Programming/Assembly

LDY - LoaD Y register

Affects Flags: S Z

Loads a memory byte (or an immediate value) into the Y register.

Examples
LDY #$00  Y register will be equal to zero
LDY $FF19  Y register will be equal to whatever the value of memory location $FF19 is

Opcodes

| Addressing mode | Syntax | Opcode | Bytes | Cycles |
|---|---|---|---|---|
| [Immediate addressing mode](500018_immediate_addressing_mode.md) | LDY #$44 | $A0 | 2 | 2 |
| Zero Page | LDY $44 | $A4 | 2 | 3 |
| Zero Page,X | LDY $44,X | $B4 | 2 | 4 |
| [Absolute addressing mode](500017_absolute_addressing_mode.md) | LDY $4400 | $AC | 3 | 4 |
| Absolute,X | LDY $4400,X | $BC | 3 | 4+ |

+ add 1 cycle if page boundary crossed
