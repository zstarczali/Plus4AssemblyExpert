# LOG Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500124
- Category: Reference/Commodore BASIC V3.5

LOG(X)

This function returns a numeric value.

This function returns the natural LOGarithm of X. The natural log is to the base e (2.71828183).

To convert to log base 10, divide by LOG(10).
