# ?ILLEGAL DEVICE NUMBER ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500166
- Category: Reference/BASIC Error Messages

An attempt was made to issue a command to a device which does not support the command (such as loading or saving a file to the screen, etc).

Example
`SAVE"TEST",0`  Causes the error by trying to save a file to device 0 (keyboard)

ERR$ error number
9
