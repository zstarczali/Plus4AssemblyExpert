# C64 to Plus/4 ROM xrefmap

- Source: https://plus4world.powweb.com/plus4encyclopedia/500293
- Category: Programming/General, Programming/Assembly

Below is a list of C64 ROM addresses and their Plus/4 equivalent. This list was compiled by Crown and Gimpy.

The page number refers to the page in the [A Commodore 64-es belső felépítése](https://archive.org/details/a_c64_belso_felepitese_1984) book, which is the hungarian version of the original [Data Becker 64 Intern](https://archive.org/details/64intern-3rd) book. Page numbers are not the same in the two editions.

Usage: the primary use is to assist in converting C64 software to Plus4 where ROM functions are called directly. If an entry is available for the exact C64 address, then the address of the Plus4 functions gives the equivalent function. It's the users responsibility to check the actual function for dependant variables/inputs/outputs in the zero page and low 1k area, and update them as well in the code being converted. If entry is not available for exact address, then you can still look at surrounding entries, compare the C64 ROM code with the matching Plus4 ROM code, and find the exact address.
