# ?MISSING FILE NAME ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500165
- Category: Reference/BASIC Error Messages

An attempt was made to access a disk drive using the [LOAD command](500051_load_command.md), [SAVE command](500058_save_command.md) or [VERIFY command](500060_verify_command.md) without specifying a filename.

Example
`LOAD"",8`  Causes the error

ERR$ error number
8
