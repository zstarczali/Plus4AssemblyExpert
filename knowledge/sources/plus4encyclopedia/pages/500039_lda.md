# LDA

- Source: https://plus4world.powweb.com/plus4encyclopedia/500039
- Category: Reference/6502, Programming/Assembly

LDA - LoaD Accumulator

Loads a byte of memory into the accumulator. Sets the Zero Flag and Negative Flags as appropriate.

Examples
`LDA #$1B  A will be equal to $1B
LDA $0314  A will be equal to whatever value is at memory location $0314`

Opcodes

| **Addressing Mode** | **Syntax** | **Opcode** | **Bytes** | **Cycles** |
|---|---|---|---|---|

| Zero Page addressing mode | LDA $00 | $A5 | 2 | 3 |
| Zero Page,X addressing mode | LDA $00,X | $B5 | 2 | 4 |
| Absolute | LDA $1000 | $AD | 3 | 4 |
| Absolute,X | LDA $1000,X | $BD | 3 | 4 (+1 if page crossed) |
| Absolute,Y | LDA $1000,Y | $B9 | 3 | 4 (+1 if page crossed) |
| (Indirect,X) | LDA ($10,X) | $A1 | 2 | 6 |
| (Indirect),Y | LDA ($10),Y | $B1 | 2 | 5 (+1 if page crossed) |
