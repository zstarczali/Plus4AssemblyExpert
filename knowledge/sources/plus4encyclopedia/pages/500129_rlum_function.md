# RLUM Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500129
- Category: Reference/Commodore BASIC V3.5

RLUM(X)

This function returns a numeric value.

This function returns the luminance level of one of the [color sources](500063_color_sources.md) specified in X (0-4).

To find the actual color, use the [RCLR function](500126_rclr_function.md).

Abbreviation
R SHIFT+L
