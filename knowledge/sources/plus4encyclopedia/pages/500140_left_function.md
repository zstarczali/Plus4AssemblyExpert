# LEFT$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500140
- Category: Reference/Commodore BASIC V3.5

LEFT$(X$,X)

This function returns string data.

This function returns the leftmost X characters of X$. It is the opposite of the [RIGHT$ function](500143_right_function.md).

Examples
`LEFT$("THE CAT IN THE HAT",7)`  Returns the string THE CAT

Abbreviation
LE SHIFT+F
