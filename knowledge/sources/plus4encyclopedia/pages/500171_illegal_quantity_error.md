# ?ILLEGAL QUANTITY ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500171
- Category: Reference/BASIC Error Messages

This occurs when a number used as the argument of a command, statement or function is outside the allowed range.

Examples
`POKE 65635,256`  The values specified are outside the range allowed by the [POKE statement](500091_poke_statement.md)
`COLOR 5,1`  The [color sources](500063_color_sources.md) used in the [COLOR statement](500068_color_statement.md) are numbered 0-4

ERR$ error number
14
