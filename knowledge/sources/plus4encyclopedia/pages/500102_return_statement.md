# RETURN Statement

- Source: https://plus4world.powweb.com/plus4encyclopedia/500102
- Category: Reference/Commodore BASIC V3.5

RETURN

This is always used with the [GOSUB statement](500078_gosub_statement.md). When RETURN is encountered, program execution continues immediately after the last GOSUB statement executed.

If a RETURN statement is encountered and there is no GOSUB in operation, a [?RETURN WITHOUT GOSUB ERROR](500169_return_without_gosub_error.md) will occur.

Abbreviation
RE SHIFT+T
