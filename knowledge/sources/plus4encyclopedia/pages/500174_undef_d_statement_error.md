# ?UNDEF'D STATEMENT ERROR

- Source: https://plus4world.powweb.com/plus4encyclopedia/500174
- Category: Reference/BASIC Error Messages

This occurs when a [GOTO statement](500079_goto_statement.md) or [GOSUB statement](500078_gosub_statement.md) points to a line number that does not exist in the program. It will also occur if an error occurs in a program with an active [TRAP statement](500111_trap_statement.md) where the line number specified in the TRAP statement does not exist.

ERR$ error number
17
