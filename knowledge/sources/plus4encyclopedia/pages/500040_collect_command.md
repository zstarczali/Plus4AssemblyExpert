# COLLECT Command

- Source: https://plus4world.powweb.com/plus4encyclopedia/500040
- Category: Reference/Commodore BASIC V3.5

COLLECT [D*drive#*] [, [ON] U*unit#*]

Validates the directory on a disk and removes any unclosed files. Using the command without arguments will validate the disk in device 8. This is the same as sending "V* drive# *" to the disk drive through a DOS channel.

Examples
`COLLECT D0`

Abbreviation
COL SHIFT+L
