# HEX$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500139
- Category: Reference/Commodore BASIC V3.5

HEX$(X)

This function returns string data.

This function returns a 4 character string containing the hexidecimal representation of X (0-65535). It is the opposite of the [DEC function](500119_dec_function.md).

Abbreviation
H SHIFT+E
