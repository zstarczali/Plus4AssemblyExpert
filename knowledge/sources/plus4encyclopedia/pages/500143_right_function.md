# RIGHT$ Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500143
- Category: Reference/Commodore BASIC V3.5

RIGHT$(X$,X)

This function returns string data.

This function returns the rightmost X characters of X$. It is the opposite of the [LEFT$ function](500140_left_function.md).

Examples
`RIGHT$("THE CAT IN THE HAT",7)`  Returns the string 'THE HAT'

Abbreviation
R SHIFT+I
