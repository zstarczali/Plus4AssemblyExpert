# PEEK Function

- Source: https://plus4world.powweb.com/plus4encyclopedia/500125
- Category: Reference/Commodore BASIC V3.5

PEEK(X)

This function returns a numeric value.

This function returns the contents of the memory loaction X (where X is in decimal format). This function is often used in conjunction with the [POKE statement](500091_poke_statement.md).

Example
`DO : LOOP WHILE PEEK(198) <> 1`  Wait until RETURN key is pressed

Abbreviation
P SHIFT+E
